<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| model `config.json` -> `_resolve_attention_topology` | A vendor-authored JSON file, not authored here, crosses into arithmetic that decides how much GPU memory is reserved. Every field is attacker-shaped in the weak sense: absent, wrong type, zero, or absurd. |
| (none new) | This plan adds no HTTP surface, no user input, no shell construction, no package installs. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure (wrong answer -> under-reserve) | `_resolve_attention_topology` layer classification | mitigate | Unrecognized `layer_types` entry or `hybrid_override_pattern` character is counted as FULL attention and appended to `warnings`, never silently stateless. Tested in Task 2 (V3). |
| T-02-02 | Tampering (misread field) | `sliding_window` branch of the chain | mitigate | The branch requires `use_sliding_window` truthy as well. 5 of 17 fixtures declare `sliding_window` with `use_sliding_window: false` and must stay dense. Dedicated regression in Task 2 (V4). |
| T-02-03 | Elevation (untestable side effect) | both helpers | mitigate | Dict in, dict out. No `open`, `glob`, `os.path`, `requests`, `/proc` or vLLM import in either body; pool size and weights are 02-02 parameters. Source-level assertion is plan 02-02's V8. |
| T-02-04 | Denial of service (crash on malformed config) | `head_dim` fallback, interval division | mitigate | `hidden_size // num_attention_heads` guarded against 0/absent head count; `num_hidden_layers // interval` guarded against interval 0. Empty dict returns zeros and raises nothing (Task 2 and 3 acceptance criteria). |
| T-02-05 | Denial of service (absurd values) | `full_bytes_per_token` arithmetic | accept | Python ints are arbitrary precision; an absurd `num_hidden_layers` produces an absurd number, not an overflow or crash. Downstream clamping is 02-02's `min(0.95, ...)`. No cost to accept. |
| T-02-SC | Tampering | npm/pip/cargo installs | accept | This plan installs nothing — pytest and stdlib only. No package legitimacy gate applies. |
</threat_model>
