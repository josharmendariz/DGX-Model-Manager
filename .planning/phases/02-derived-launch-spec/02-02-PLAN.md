_kv_budget_gb(util: float, pool_gb: float, weights_gb: float,
              overhead_gb: float = 6.0, resident_gb: float = 0.0) -> float
  == max(0.0, pool_gb * util - resident_gb - weights_gb - overhead_gb)

_derive_launch_spec(config: dict, weights_gb: float = 0.0, pool_gb: float = 121.0,
                    kv_dtype_bytes: int = 1, overhead_gb: float = 6.0,

    bounded_kv_layers      int
    stateless_layers       int
    source_field           str   the precedence field that resolved the topology, echoed from
                                 topology["source_field"]: "layer_types" |
                                 "hybrid_override_pattern" | "full_attention_interval" | "dense"

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| vendor `config.json` -> `_derive_launch_spec` | A JSON file authored outside this repo crosses into arithmetic whose output is a `--gpu-memory-utilization` value and a `--max-model-len`. Fields may be absent, wrong-typed, zero, negative or absurd. |
| caller-supplied scalars -> `_derive_launch_spec` | `weights_gb`, `pool_gb`, `resident_gb` come from a Phase 4 caller that will read them off the box. This plan treats them as untrusted inputs so the pure function stays the choke point. |
| (none new) | No HTTP surface, no user input, no shell construction, no package installs in this plan. |
